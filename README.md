## ⚙️ Backend Architecture — JavaScript API Orchestration Layer

<sub>The AI layer behind almost every build here runs through a small, hand-tuned JavaScript backend — not a framework showcase, a deliberately thin one. Its only job is to sit between the browser and an LLM endpoint and make that round-trip fast, cheap, and hard to break.</sub>

<br/>

**Runtime & pattern**

A Node.js serverless/edge function (Vercel Functions / Netlify Functions) fronts every Groq LPU or Anthropic Claude call. The client never talks to the model provider directly — every API key stays server-side, injected from environment variables, never bundled into client JS.

**Optimizations applied across the JS backend layer**

- **Streaming responses** — completions are piped to the client as Server-Sent-Event-style chunks instead of waiting for the full payload, cutting perceived latency to first-token
- **Exponential backoff + jitter** — transient `429`/`5xx` responses from the LPU/LLM endpoint get up to 3 retries with growing delay instead of failing the request outright
- **Prompt-hash response caching** — a hash of the normalized prompt is used as a cache key so repeated queries skip the network round-trip entirely
- **Client-side debouncing** — keystroke-triggered calls (live search, streamed math grids) are throttled to one request per pause, not one per keystroke
- **Regex-based offline fallback** — when the upstream API is unreachable or rate-limited, a deterministic local generator keeps the UI functional instead of showing a dead screen
- **Locked-down CORS** — proxy endpoints only accept requests from the deployed origin, no wildcard origins
- **AbortController timeouts** — every upstream fetch carries a hard timeout so one slow provider call can't hang the whole request

**A representative (illustrative) pattern from this layer:**

```javascript
// api/groq-proxy.js — Node.js edge/serverless function
export default async function handler(req, res) {
  const cacheKey = hashPrompt(req.body.prompt);
  const cached = await edgeCache.get(cacheKey);
  if (cached) return res.status(200).json(cached);

  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), 8000);

  for (let attempt = 0; attempt < 3; attempt++) {
    try {
      const upstream = await fetch(GROQ_ENDPOINT, {
        method: "POST",
        headers: { Authorization: `Bearer ${process.env.GROQ_API_KEY}` },
        body: JSON.stringify(buildPayload(req.body)),
        signal: controller.signal,
      });
      clearTimeout(timeout);
      return streamToClient(upstream, res, cacheKey); // SSE-style chunking
    } catch (err) {
      if (attempt === 2) return res.status(200).json(offlineFallback(req.body));
      await sleep(2 ** attempt * 250); // exponential backoff + jitter
    }
  }
}
```

### .github/workflows/snake.yml — Contribution Snake Animation

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    timeout-minutes: 10

    steps:
      - name: Generate GitHub Contribution Snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push snake animation to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
